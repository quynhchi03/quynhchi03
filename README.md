# 🚀 Highlight Projects

## 📶 Smart Indoor Navigation System
> **Tech Stack:** ESP32 | Python | BLE | Machine Learning

- Built an indoor localization system using Bluetooth Low Energy signals.
- Processed RSSI data and optimized positioning accuracy with lightweight ML models.
- Designed for smart buildings and navigation assistance.

---

## 🤖 AI Voice Assistant for Smart Devices
> **Tech Stack:** Python | Speech Recognition | Embedded AI

- Developed a mini AI assistant capable of voice interaction and device control.
- Connected hardware modules with intelligent response logic.
- Focused on real-time processing and low-resource deployment.

---

## 🌐 IoT Environmental Monitoring Platform
> **Tech Stack:** ESP32 | MQTT | Firebase | Dashboard UI

- Created a real-time monitoring system for temperature, humidity, and air quality.

- Improved remote monitoring and alert capabilities.
